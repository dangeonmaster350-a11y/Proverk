# 💬 Volt Messenger

Защищённый мессенджер. Исходный код разбит на 3 файла:

| Файл | Описание |
|------|----------|
| `index.html` | HTML-страница (точка входа) |
| `styles.css`  | Все стили (темы, компоненты, анимации) |
| `app.js`      | Логика приложения (данные, экраны, функции) |

## Запуск

Откройте `index.html` в браузере — без сервера, всё работает локально.

## Тестовые аккаунты

| Номер / Username | Пароль | Тип |
|------------------|--------|-----|
| `+9995632`       |          | 👑 Владелец |
| `alexey_k`       |          | Обычный |
| `marina_v`       |          | Обычный |
| `dmitry_p`       |          | Обычный |
| `+8881234567`    |          | 👤 Анонимный номер |
| `+8889999888`    |          | 👤 Анонимный Номер |

Также можно войти по нику без проверки пароля через вкладку «По нику».

## Анонимные номера

Любой номер начинающийся с `888` — анонимный. Premium активируется автоматически.
